# 29. Definition of Done

A module is considered complete only when all of the following are satisfied:

1. Implementation is complete and reviewed.
2. Automated tests cover the core behavior.
3. Documentation is updated for the module and its public contracts.
4. OpenAPI documentation exists for any exposed endpoints.
5. Logging, validation, and error handling are implemented consistently.
6. Security and tenant-awareness concerns have been reviewed.
7. The change is merged through the standard workflow.
